Browser Bridge

Set up Browser Bridge

Browser Bridge joins two pieces: this extension and a local bridge that any MCP client can use. Together they let one AI assistant read and operate one browser tab.

Two steps

  1. Start your MCP client

    Add the server to your MCP client and start a session. The first client to connect starts a shared bridge in the background; later clients join the same bridge, so several assistants can use it without fighting over a port.

  2. Connect a tab

    Open the page you want the assistant to use, then open the popup and choose Connect tab. One tab is connected at a time, and every MCP client on this computer shares that tab. Choose Disconnect when you are done.

Point your MCP client at the server

The server speaks MCP over standard input and output. Use your client's usual server settings and replace the path with the built server file on this computer.

Claude Code

claude mcp add browser-bridge -- node C:\path\to\browser-bridge-mcp\packages\server\dist\index.js

JSON settings for other clients

{
  "mcpServers": {
    "browser-bridge": {
      "command": "node",
      "args": ["C:\\path\\to\\browser-bridge-mcp\\packages\\server\\dist\\index.js"]
    }
  }
}

Cursor, Claude Desktop, VS Code, Cline, Windsurf, Zed and other client apps place this block in different files. Keep the command and arguments the same; the client's own documentation shows where the file lives. Every client can point at the same server file: the first one starts the shared bridge and the rest reuse it.

The bridge listens on port 8787, and this extension is built for that port. If another program owns 8787, stop it and choose Try again. Run the server with --stop to shut the shared bridge down.

What the assistant can do

  • Open a web address, go back, or go forward
  • Read an accessible outline of the page with element references
  • Click, hover, type, or select an option
  • Press a key or a keyboard shortcut
  • Drag between two elements with the pointer
  • Wait for the page to settle
  • Read recent console messages
  • Read recent network request metadata, without headers or bodies
  • Take a screenshot of the visible page

Pages Chrome will not share

Chrome blocks automation on some surfaces. The extension will say so instead of pretending to work.

  • chrome:// pages, including settings and the new tab page
  • The Chrome Web Store and other extension galleries
  • Other extension pages, including this one
  • PDF pages in Chrome's viewer
  • Any tab that already has DevTools open: Chrome allows one debugger per tab

Where your data goes

The shared bridge listens only on your own loopback address. Page content, screenshots, console messages and network metadata move between this extension, the bridge and the MCP clients on this computer. Network metadata keeps URLs, status and timing, but never headers, cookies or bodies. The bridge itself does not send anything to another machine.

The bridge accepts the extension from this Chrome profile and connections from local programs that speak its client protocol, with no password. Only install extensions and agents you trust: every MCP client that connects can read and operate the tab you connect.

Your MCP client may send tool results to the model provider that powers it. That transfer is between you and that client, not something this extension does.

If something goes wrong

The popup says the server did not answer
Start an MCP client that has the server configured, then choose Try again. The first client starts the bridge; after that, other clients join it.
Another browser session is already connected
One Chrome tab session can use the bridge at a time. Disconnect the other extension session, then connect this tab again.
Connection lost while a page was open
Open the popup and choose Try again. The extension also retries on its own while a session is active.
The tab disappeared
Open the page again, then connect the new tab from the popup.
Chrome stopped debugging the tab
Close DevTools for that tab, then connect it again from the popup.
Two assistants disagree about the page
They share one tab. Ask each assistant to take a new snapshot before its next action.

Browser Bridge keeps automation on this machine. You can stop it at any time with Disconnect.
